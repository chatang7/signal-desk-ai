# SIGNAL DESK v2 — 공개 소스 자동 수집판

## 1. 실행

- `index.html`을 Chrome 또는 Edge에서 열고 왼쪽 **자동 수집 → 지금 동기화**를 선택합니다.
- 인터넷에 연결되어 있으면 **GitHub 공식 릴리스 API**와 **Hugging Face Daily Papers API**에 브라우저에서 직접 요청합니다.
- 처음 열면 `자동 확인`이 기본으로 활성화되어 있어 이전 시도 후 6시간이 지났을 때 자동으로 수집합니다. 사이트가 열려 있는 동안 30분마다 조건을 확인합니다. **브라우저를 닫으면 수집하지 않습니다.** 이것은 서버 백그라운드 수집이 아닙니다.
- 일부 환경(`file://`, 회사 네트워크, 광고 차단기)에서 CORS/네트워크 정책으로 실패할 수 있습니다. 수집 탭에서 출처별 오류를 확인하고 필요하면 HTTPS 정적 호스팅 서비스에서 실행하세요. 실패했다고 사실을 추측해 채워 넣지는 않습니다.

## 2. 수집하는 공식 공개 소스

GitHub 릴리스: OpenAI Codex, Gemini CLI, Claude Code, Transformers, vLLM, Ollama, ComfyUI, llama.cpp. 각 저장소에서 최근 최대 2개 정식 릴리스를 확인하며, 게시된 지 45일이 지난 릴리스는 건너뜁니다.

연구 논문: Hugging Face Daily Papers API 최근 목록을 받아 원문 arXiv 링크를 기록합니다. 연구 결과의 동료 평가와 독립 재현 여부는 검증하지 않습니다.

수집 중 기록하는 값: 실제 원문 URL, 프로젝트·릴리스 제목, 공개일, 공식 설명 일부, 출처, 수집 시각. **비용·실제 성능 수치·중요성·가격등급은 확인되지 않았으면 빈 값/미정으로 유지**합니다. 자동 수집은 검증 완료와 다릅니다.

GitHub API는 비인증 호출 제한이 있으며, Hugging Face API는 CORS 정책에 따라 요청이 실패할 수 있습니다. 설정의 체크박스로 호출 대상을 줄일 수 있습니다.

## 3. 중복 처리 및 검토

- 같은 외부 항목 ID 또는 정규화된 원문 URL은 이미 있으면 새로 만들지 않습니다.
- 동일 URL로 다른 출처에서 발행한 소식도 하나로 저장합니다. 유사 제목의 다른 기사들은 기존의 중복 후보 보기에 묶이고 원본은 유지됩니다.
- **사용자가 수정한 검토 상태, 메모, 우선순위, Discord 선택 상태는 재수집 시 덮어쓰지 않습니다.**
- 수동 Markdown 및 JSON 가져오기에서도 동일 ID/링크/동일 제목과 날짜를 중복 저장하지 않습니다.
- 기존 기능(분류·검색·정렬·무료/저비용 필터·Discord 문안 편집·JSON/CSV 백업)을 그대로 유지합니다.

## 4. 사용자 지정 JSON 브리핑 피드

**자동 수집 → 맞춤형 JSON 브리핑 피드**에 CORS를 허용하는 **HTTPS JSON URL**을 등록하면 다른 공개 브리핑의 뉴스 항목을 수집할 수 있습니다. URL에는 비밀번호·API 토큰을 포함하지 마세요. 피드 안에는 JSON 배열이나 `{ "items": [ ... ] }` 형태의 레코드가 필요하며, 제목과 하나 이상의 유효한 HTTP(S) 링크가 필수입니다. `example-feed.json`을 참고하세요.

**이 기능은 ChatGPT 예약 브리핑의 자동 전송을 구현한 것이 아닙니다.** ChatGPT의 예약 작업이 해당 JSON URL에 데이터를 쓰도록 설정된 상태가 아니며, 이를 위해서는 별도의 백엔드와 인증된 데이터 전달 경로가 필요합니다. 현재 기존 일일 브리핑 예약 작업은 수정하지 않았습니다.

## 5. 아직 미정인 것

- ChatGPT 예약 브리핑 결과를 대시보드로 서버 간 자동 전달
- 24시간 서버 수집, 로그인, 여러 기기 상태 동기화
- 국내외 종합 AI 기업 뉴스 전체 자동 수집 및 AI 수준의 의미 중복 검사
- 인용문/수치/가격 자동 사실 검증, Discord 자동 게시

## 6. 기존 v1 데이터 이전

**동일한 브라우저 origin에서 연 경우** v1의 `signal-desk-v1` 데이터와 Discord 초안(`signal-desk-discord-v1`)을 그대로 읽습니다. 단독 HTML 파일의 경로·파일명이 바뀌거나, 다른 브라우저에서 실행한다면 브라우저별 저장 공간이 분리될 수 있습니다. 기존 대시보드에서 **운영 설정 → 전체 데이터 JSON 백업** 후 v2에서 **가져오기** 하는 것이 가장 안전합니다. 백업 가져오기는 기존 동일 레코드를 중복 생성하지 않습니다.

새 수집 설정 키: `signal-desk-sync-v2`. API 토큰을 로컬 저장하지 않습니다.

## 7. 검증 범위

실행 시 JavaScript 구문 검사 및 Chromium Playwright 모의 API 응답 테스트를 실시했습니다. 신규 2건 등록, 2회차 중복 제외, 검토 상태 보존, 모바일 가로 넘침 없음, JavaScript 런타임 오류 없음이 확인되었습니다. **실제 외부 서비스에 대한 요청 성공 여부는 현재 환경에서 별도 검증하지 못했습니다.**

## 8. 데이터 안전

뉴스와 검토 상태는 계속 해당 브라우저 `localStorage`에 저장됩니다. 정기 JSON 백업을 권장합니다. API 요청은 브라우저에서 제3자 서비스(GitHub, Hugging Face, 선택한 JSON URL)로 직접 전송되며, 해당 서비스의 이용약관/레이트 리밋을 따릅니다.
